## О проекте

Профессиональная панель управления (dashboard) с аутентификацией, валидацией данных и подключением к базе данных. Проект демонстрирует современные подходы к созданию защищенных и масштабируемых веб-приложений.

## Демо

👉 [Посмотреть живую демонстрацию](https://dashboard-ivory-eight-25.vercel.app/dashboard)

## Технологический стек

- **Frontend Framework**: Next.js
- **UI Library**: React
- **Styling**: Tailwind CSS
- **Authentication**: Next-Auth
- **Validation**: Zod
- **Security**: bcrypt
- **Database**: PostgreSQL
- **Language**: TypeScript
- **Markup**: HTML5
- **Styling**: CSS3

## Ключевые особенности

- Полноценная система аутентификации
- Валидация данных на клиенте и сервере
- Защищенное хранение паролей (bcrypt)
- Резиновая и адаптивная верстка
- Современный UI с графиками и статистикой
- Строгая типизация (TypeScript)
- Интеграция с PostgreSQL

## Функционал

✅ Авторизация и аутентификация пользователей  
✅ Валидация форм (Zod)  
✅ Защищенные маршруты  
✅ Интерактивные графики и диаграммы  
✅ Адаптивный интерфейс  
✅ CRUD операции с данными  
✅ Темная/светлая тема  

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/VladimirMedv/dashboard.git
```

2. Установите зависимости:
```bash
npm install
# или
yarn install
```

4. Запустите development сервер:
```bash
npm run dev
# или
yarn dev
```

5. Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## Скрипты

- `dev`: Запуск development сервера
- `build`: Сборка production версии
- `start`: Запуск production сервера
- `lint`: Проверка кода с ESLint
- `type-check`: Проверка TypeScript типов
